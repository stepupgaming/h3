# Purpose

Internalized ComfyUI product pack for MiniMax-H3 generate (`gemmy video h3 --engine comfy`).

# Ownership

- This tree is **part of** `runtimes/minimax-h3` — production engine code, not a research checkout.
- Hosts the H3 headless runner, graph builder, pinned accel custom_nodes (incl. **ComfyUI-NVIDIA-RTX-VSR-Pro** for `gemmy video h3 upscale --backend rtx` and **ComfyUI-NVIDIA-DLSS-Frame-Interpolation** for `gemmy video h3 interpolate`), and H3 setup notes.
- Weights stay **external** via `GEMMY_H3_CHECKPOINTS` (runner writes a runtime `extra_model_paths.yaml` including `latent_upscale_models/`, `ultralytics/`, `ultralytics_bbox`, **Eros** `GEMMY_H3_EROS_CHECKPOINTS`, **stock Ref2VA backup** `GEMMY_H3_REF2VA_STOCK` / `G:\Models\minimax-h3-backup`, **Singularity** `GEMMY_H3_SINGULARITY_CHECKPOINTS` / `F:\Models\minimax-h3-singularity`, **Junkun hybrid** `GEMMY_H3_HYBRID_CHECKPOINTS` / `C:\Models\minimax-h3-hybrid` (diffusion_models, loras, latent_upscale_models), and **RefMods** `GEMMY_H3_REFMODS` / `<checkpoints>/refmods`). Persistent `:8188` Comfy reads the on-disk `extra_model_paths.yaml` (regenerated by `gemmy audio-h3 install`).
- Gemmy worker: `../gemmy_h3_comfy_generate.py`.

# Local Contracts

- Entry: `run_h3_workflow.py`. `--serve` + `GEMMY_H3_COMFY_SERVE` keep one process for multi-window continue. Loaders intern UNET/CLIP/VAE by filename and clone the cached patcher; do **not** `unload_all_models` between windows (a second disk-load of the 32B TE + DiT hard-locked this 16 GB box). Single-window generate still one process.
- Graph builder: `h3_workflow_build.py` (mode × turbo × realism × sol × cache × `shift_video`/`shift_audio`). `0/0` skips `MiniMaxH3SigmaShift`; stock and both source shortfilm graphs use 12/3. `continuation_mode=latent_refine` is the LBH second sample (enlarge leftover AV latent → ManualSigmas euler or `--denoise` KSampler). CLIPLoader is `device=cpu` for the 32B NVFP4 TE — GPU TE access-violates on 16 GB.
- Pins: `h3_custom_nodes_pins.json` (turbo + realism_people LoRA + **ComfyUI-NVIDIA-RTX-VSR-Pro** + required **`gemmy-h3-context`** + **ComfyUI-Ref2VA-VSA** for `--vsa` + **ComfyUI-PixelForge-H3** for `video h3 sprites` + **ComfyUI-NVIDIA-DLSS-Frame-Interpolation** for `video h3 interpolate` + **ComfyUI-MiniMaxH3Mod** for `video h3 refmod` / generate and continue `--ref-mod`). Optional packs (`Comfyui_Minimax_h3_latent_Upscaler`, `ComfyUI-H3-FaceRefine`, **`ComfyUI-H3-Motion-Context` v0.3.1**, **`ComfyUI-MiniMax-H3-009jev`**) live under `optional_pins` — never required for default generate. Motion Context is GPL-3.0 (speech FL2VA only). 009jev is GPL-3.0 `H3JevNativeSLAPatch` only (`gemmy video h3 generate --jev` omit-steps=4-step res_multistep, `--jev --steps 20`=HQ euler, or `--sla-fixed 1|3|5|10` or `--sla-table PATH` N×50; dedicated `runtimes/minimax-h3/jev-sdk` for adaptive only; not W4A4). NVIDIA DLSS SDK DLLs and demo Assets under the DLSS pin are gitignored (local Git LFS).
- **`custom_nodes/gemmy-h3-context/`** — Gemmy-owned AV persist, `native_guide` (`GemmyH3LatentTailGuide`) / `masked_av` / VAE-tail / trim-prefix, SatoDive **Native Guide stitch** (`stitch_continuation.py`: cut source at the re-rendered tail, colour-match, source audio through overlap), Split+Join, **`GemmyH3InitFromAudio`**, **`GemmyH3EncodeVideoFrames`**, **`GemmyH3SetAVNoiseMask`**, **`GemmyH3SaveConditioning`** / **`LoadConditioning`** and **`GemmyH3SaveSigmas`** / **`LoadSigmas`** (Singularity writes these, then the process exits). Do not pin the Easy director pack; stitch + keyframe recipe are harvested MIT from SatoDive/nkxx188. Frozen `ref_audio` is context (`audio_update=False`). Init-from-audio writes a wav into the **target** audio half so KSampler `denoise` < 1 can walk it (audio img2img). That is not lock: `audio_mode=source_track` / mask 0 keeps the source voice exactly. VAE-tail takes the last snapped video frames **and** the matching audio tail (imported MP4s are longer than context). Product mask-edit does **not** use Encode+noise_mask: the crop is Ref2VA `ref_video`, empty 0.2 MP `ganloss_two_stage`, then `latent_refine` 3D SR + 3-step (ganloss `2026-08-31 minimax_h3_r2v_video_mask_edit.json` on two 16 GB processes). Crop/uncrop/overlay live in `runtimes/minimax-h3/h3_mask_edit.py`. Do not vendor ethanfel/seitanism GPL UI or drozbay MaskVidExperiments (GPL-3.0).
- **Pinned Comfy core: v0.36.0** (`ee71d5c` tag). Native H3 VAE + `MiniMaxH3AddGuide` + chunked I/O. Do **not** full-pull Comfy master over this tree. `SaveVideo` `format` is a DynamicCombo: API graphs must send the option key (`"auto"`) plus dotted `format.codec`, same pattern as LBH `mode.scale`. `run_h3_workflow.py` rewrites packaged 0.33.4 string `format`/`codec` into that shape; a nested dict in `format` is dropped by the V3 expander. Keep custom_nodes pins separate.
- **Gemmy-only Windows load patch:** `comfy/utils.py` `--disable-mmap` uses safetensors `backend=pread` (not mmap + `copy=True`) so the 32B TE does not charge the pagefile. Re-apply after any core overlay.
- Headless runner stub must expose `PromptServer.instance.node_replace_manager.register`.
- Python pins matching this tag: `comfy-kitchen==0.2.34` (fused fp16/int8 VAE decode + `sol_attn` for `--vsa`), `comfy-aimdo==0.5.3` (pin only; **never enable** AIMDO), `comfyui-frontend-package==1.52.7`, `av>=17.0.0`.
- Live sampler preview is headless: if `GEMMY_LIVE_PREVIEW` is set, `run_h3_workflow.py` uses `--preview-method auto` and `set_progress_bar_global_hook` to write Latent2RGB JPEGs. Default remains `NoPreviews` when that env is unset. Do not launch Comfy's HTTP/WS server for Nightshift.
- Production default path: this directory. Dev override only: `GEMMY_H3_COMFY`.
- Realism People LoRA: plain `LoraLoaderModelOnly` after turbo; file `h3-realism-people-t2v-i2v-r2v.safetensors`; trigger `r34l1sm`.
- No disk weight offload. Runner always injects `--disable-dynamic-vram` + `--disable-mmap` + `--disable-pinned-memory` and asserts `aimdo_enabled=False`. It also injects `--fast fp16_accumulation` so the H3 video VAE encoder uses kitchen `fp16_conv3d`. That is the only `--fast` feature. A bare `--fast` (which also enables fp8 matmul, cublas_ops, and autotune) is not injected. MiniMax H3 `supported_inference_dtypes` stays bf16/fp32, so this does not retarget the DiT. No auto multi-model downloads.
- Scratch `input/` `output/` `temp/` `user/` gitignored.
- Lab twin `C:\Projects\minimax-h3\ComfyUI` is reference only; product does not require it.

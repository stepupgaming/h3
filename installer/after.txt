h3 is installed and the setup step has run.

Open a new terminal so PATH picks it up, then:

  h3 doctor
  h3 generate --first-frame still.png --prompt "..." --duration 5 -o clip.mp4

If you already have ComfyUI, point h3 at that folder:

  h3 setup --comfy C:\path\to\ComfyUI

Weights live outside the install folder. h3 install can be run again; files already on disk are skipped.
